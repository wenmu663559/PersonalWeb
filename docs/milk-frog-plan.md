# 奶蛙弹跳大冒险实施计划

现有主页为原生静态网站，GitHub Actions 构建 dist 并部署 GitHub Pages。游戏独立于主页 JS，使用 game/ 内的 Phaser 3 + Matter + TypeScript + Vite，构建产物复制到 dist/game，使用相对资源路径支持仓库子路径和 iframe。

1. 实现原创黄色圆肚凸眼角色与固定碰撞体，集中配置蓄力和物理参数。
2. 实现稳定着地蓄力、方向性尖刺击退、单尖刺冷却与跨尖刺连续碰撞。
3. 完成关卡、检查点、掉落复位、终点、计时、成绩和暂停重开。
4. 集成独立入口、静态构建和安全的本地预览路径。
5. 执行物理逻辑测试、TypeScript 检查、生产构建与浏览器交互验收。

素材策略：项目中未发现用户提供的奶蛙参考图片。使用代码绘制原创奶黄色胖蛙，不下载来历不明的素材；视觉形变不改变物理碰撞体。

需求原文截止在 5.4 第 5 条，当前实现以已给出的需求为准，不推断尚未提供的后续规则。
