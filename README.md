# FORM® — 个人数字工作室

暖白编辑式排版、橙红强调色、实时三维粒子雕塑，以及完整 Node.js 后端。无第三方运行依赖，无需安装依赖或构建。需要 Node.js 22 或更新版本。

## 启动

```sh
npm start
```

打开 http://localhost:3000 。开发时使用 `npm run dev` 自动重启后端，修改页面后刷新浏览器。可用环境变量 `PORT` 更改端口、`HOST` 更改监听地址，默认只监听本机 127.0.0.1。

## 文件与定制

- `content.js`：作品、随笔、首屏姓名。所有项目和人物目前都是示例内容。
- `public/index.html`：首页文案、关于介绍、页脚姓名及 SEO 信息；更换身份时一起更新。
- `public/style.css`：全站样式、响应式布局、过渡和滚动效果。
- `public/app.js`：粒子雕塑、作品筛选、详情、表单与动效控制。
- `server.js`：内容 API、留言校验、持久化、限流及安全响应头。

## 交互

- 首屏粒子雕塑由 Canvas 实时计算，鼠标移动改变视角；右下角可暂停动画。
- 自动尊重系统“减少动态效果”，画布离屏和浏览器后台时停止渲染。
- 作品支持分类筛选与详情阅读；随笔可点击打开全文。
- 联系弹窗具备必填、邮箱和长度校验，支持发送中、成功、失败及超时反馈。
- 对话框支持 Esc 关闭、焦点约束和返回触发按钮。

## 后端与数据

- `GET /api/content`：个人资料、作品与随笔；支持 ETag 条件缓存。
- `POST /api/contact`：接收 JSON `{ name, email, message, website? }`。有效留言追加至 `data/messages.jsonl`；`website` 为反机器人蜜罐字段，应留空。
- `GET /api/health`：服务健康状态。
- 单 IP 每 10 分钟最多 5 次提交尝试；JSON 请求体限制为 16 KB。
- 写入使用队列串行化，只有持久化成功才返回成功；数据目录不向网页暴露，并已加入 `.gitignore`。
- 留言仅保存本地，不会自动发送邮件；站长可直接查看 JSONL 文件。当前没有公开后台或登录系统。
- 默认限流为单进程内存计数，重启会清空；如部署多个实例，应使用共享限流存储。反向代理部署需保留 Host/Origin，并另行配置 HTTPS、持久卷和备份。

## 验证

```sh
npm test
```

测试通过真实 HTTP 请求检查内容读取、留言落盘、无效输入、跨站拒绝、限流、方法约束、私有文件隔离、非法 JSON、请求体上限和条件缓存。测试使用临时数据目录，不产生用户留言。
