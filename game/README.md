# 奶蛙弹跳大冒险

Phaser 3.90 + 内置 Matter.js，TypeScript，Vite。无需后端。角色、地形和尖刺均由代码绘制，黄色奶蛙是原创替代形象，不包含网络角色图片或第三方素材。

## 开发

```sh
npm ci
npm run dev
npm test
npm run build
```

生产文件位于 `game/dist/`。根项目构建将其复制到主页 `dist/game/`，使用相对资源路径兼容 GitHub Pages 子目录。

## 操作

- 鼠标或触屏按住蓄力，松开跳跃；键盘 Space 同样可用。
- 必须落稳后才能开始蓄力。短于 0.1 秒不跳跃，1.5 秒满力，最多记录 1.8 秒。
- R 重开，Esc 暂停/继续；移动端使用页面按钮。
- 深坑回到最近检查点；尖刺不致死，按其朝向击飞，可连续碰撞其他尖刺。
- 半程平台落稳后激活检查点；到达终点保存本机最快成绩。存储不可用时不影响游玩。
- 声音默认关闭，需主动开启。失去焦点或切后台自动暂停。

`src/physics.ts` 集中保存蓄力、跳跃和尖刺物理参数。三角形碰撞体与其描画顶点一致。角色碰撞体始终是固定圆形，蓄力、起跳、落地形变只改变视觉容器。

尖刺碰撞回调只计算与排队击退速度，下一次 Scene.update 在 Matter 碰撞求解后应用，避免求解器覆盖击飞效果。每个尖刺有独立冷却，其他尖刺仍可继续触发连弹。

添加 `?debug=1` 可在浏览器控制台调用只读 `window.__frog()` 检查位置、着地、蓄力、跳跃、碰撞和检查点状态。它不提供修改游戏状态的接口。

最高成绩和声音偏好保存在 localStorage，不上传网络。Giscus 与个人主页接口不是游戏运行依赖。
